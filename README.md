# Easy Valet - نظام إدارة تقارير الفاليه المتقدم

نظام احترافي لإدارة وتتبع عمليات خدمة صف السيارات (Valet) وإصدار التقارير اليومية والشهرية بدقة عالية.

## المميزات الرئيسية
- **إدارة التقارير اليومية:** تسجيل الإيرادات، عدد السيارات، وتوزيعها على الفنادق.
- **تحليلات شهرية متقدمة:** رسوم بيانية تفاعلية (Pie & Bar Charts) لتوزيع الإيرادات وأداء الفنادق.
- **نظام ZAPS:** إدخال سريع لعمليات الفنادق بأسعار تلقائية متغيرة حسب الموقع.
- **روابط المشاركة التفاعلية:** إمكانية مشاركة التقارير عبر روابط فريدة تعمل على كافة الأجهزة بدون الحاجة لتسجيل دخول.
- **تصدير Excel:** توليد تقارير Excel احترافية بضغطة زر.
- **نظام إشعارات البريد:** إرسال التقارير تلقائياً عبر الإيميل.

## المتطلبات التقنية
- **Next.js 15+** (App Router)
- **Turso DB** (LibSQL)
- **Tailwind CSS**
- **Recharts** (للرسوم البيانية)

## طريقة التشغيل محلياً
1. قم بتحميل المستودع:
   ```bash
   git clone [repo-url]
   ```
2. تثبيت المكتبات:
   ```bash
   npm install
   ```
3. إعداد البيئة:
   قم بإنشاء ملف `.env.local` بناءً على `.env.example`.
4. تهيئة قاعدة البيانات:
   ```bash
   node scripts/init.js
   ```
5. تشغيل السيرفر:
   ```bash
   npm run dev
   ```

## النشر على Vercel
1. قم بربط المستودع بـ Vercel.
2. أضف متغيرات البيئة الموجودة في `.env.example` في إعدادات Vercel.
3. استمتع بالتطبيق!
